Синтаксис Haxe

Точка входа

Любая программа начинается с класса, содержащего статический метод main:

class Main {
  static function main() {
    trace("Hello, Haxe!");
  }
}

Переменные

Объявление через var, тип опционален (выводится компилятором):

var name:String = "Haxe";
var age:Int = 10;
var ratio:Float = 0.5;
var flag:Bool = true;

Константы и литералы

  • Целые: 0, -134, 0xFF00
  • Дробные: 123.0, .14179, 13e50
  • Строки: "hello", 'hello "world"'
  • Логические: true, false
  • null — специальное значение для любого типа [citation:2]

Операции (по приоритету)

  • Присваивание: =, +=, -=, *=, /=
  • Логические: ||, &&
  • Сравнения: ==, !=, >, <, >=, <=
  • Битовые: |, &, ^, сдвиги <<, >>
  • Арифметические: +, -, *, /, % [citation:2]

Условия

if (age > 18) {
  trace("взрослый");
} else if (age > 12) {
  trace("подросток");
} else {
  trace("ребёнок");
}

Циклы

for (i in 0...5) {
  trace(i); // 0,1,2,3,4
}

var arr = [10, 20, 30];
for (item in arr) {
  trace(item);
}

while (condition) {
  // ...
}

Функции

function sum(a:Int, b:Int):Int {
  return a + b;
}

// значение по умолчанию
function greet(name:String = "мир"):String {
  return "Привет, " + name;
}

Блоки

Блок { ... } содержит несколько выражений. Значение блока — значение последнего выражения. Пустой блок имеет тип Void [citation:2].
