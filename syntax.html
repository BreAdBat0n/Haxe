Синтаксис Haxe

Синтаксис Haxe похож на C-подобные языки (Java, C#, ActionScript): фигурные скобки, точки с запятой, классы и функции. Но есть и свои особенности — например, выражения как значения и мощный вывод типов.

Точка входа

Любая программа начинается с класса, содержащего статический метод main:

class Main {
  static function main() {
    trace("Hello, Haxe!");
  }
}

Переменные

Объявление через var, тип опционален (выводится компилятором):

var name:String = "Haxe";
var age:Int = 10;
var ratio:Float = 0.5;
var flag:Bool = true;
var nothing = null; // Dynamic/Null

Переменные можно объявлять без инициализации, но использовать до присваивания нельзя:

var x:Int;
x = 5; // ok
trace(x);

Константы и литералы

  • Целые: 0, -134, 0xFF00, 0b1010
  • Дробные: 123.0, .14179, 13e50
  • Строки: "hello", 'hello "world"'
  • Логические: true, false
  • null — специальное значение для любого типа

Операции (по приоритету)

  • Присваивание: =, +=, -=, *=, /=, %=, &=, |=, ^=, <<=, >>=, >>>=
  • Логические: ||, &&
  • Сравнения: ==, !=, >, <, >=, <=
  • Битовые: |, &, ^, сдвиги <<, >>, >>>
  • Арифметические: +, -, *, /, %
  • Унарные: !, ~, ++, --, +, -

Строки конкатенируются через +. Для интерполяции используйте 'строка ${переменная}':

var n = 5;
trace('значение: ${n}'); // значение: 5

Условия

if (age > 18) {
  trace("взрослый");
} else if (age > 12) {
  trace("подросток");
} else {
  trace("ребёнок");
}

Тернарный оператор:

var status = age >= 18 ? "adult" : "minor";

Циклы

for (i in 0...5) {
  trace(i); // 0,1,2,3,4
}

var arr = [10, 20, 30];
for (item in arr) {
  trace(item);
}

while (condition) {
  // ...
}

do {
  // ...
} while (condition);

Цикл по ключам и значениям (для Map):

var map = ["a" => 1, "b" => 2];
for (k in map.keys()) {
  trace(k + " = " + map[k]);
}

Функции

function sum(a:Int, b:Int):Int {
  return a + b;
}

function greet(name:String = "мир"):String {
  return "Привет, " + name;
}

var fn = function(x:Int) return x * 2;

Блоки как выражения

Блок { ... } содержит несколько выражений. Значение блока — значение последнего выражения. Пустой блок имеет тип Void.

var x = {
  var a = 10;
  var b = 20;
  a + b; // значение блока = 30
};
trace(x); // 30

Switch

var value = 2;
switch (value) {
  case 1: trace("один");
  case 2, 3: trace("два или три");
  default: trace("другое");
}

Switch в Haxe — выражение, поэтому его можно присваивать:

var text = switch (value) {
  case 1: "один";
  case 2: "два";
  default: "другое";
};

Try / Catch

try {
  throw "ошибка";
} catch (e:String) {
  trace("поймано: " + e);
}

Пакеты

Пакет задаётся через package в начале файла:

package utils;

class Helper {
  public static function add(a:Int, b:Int):Int return a + b;
}

Файл должен лежать в utils/Helper.hx.

Область видимости

  • public — доступно отовсюду
  • private — только внутри класса
  • static — принадлежит классу, а не экземпляру
  • inline — подставляется в место вызова
  • override — переопределение метода родителя
  • final — запрет переопределения

NULL-безопасность

По умолчанию null можно присвоить любому типу, но для строгой проверки используйте Null<T> или флаг -D null-safety.

var maybe:Null<Int> = null;
