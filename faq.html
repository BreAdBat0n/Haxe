Типовые вопросы

Haxe — это фреймворк?

Нет. Haxe — это язык и инструментарий (компилятор + стандартная библиотека). Сторонние библиотеки подключаются через haxelib.

Как скомпилировать в JavaScript?

Используйте флаг -js: haxe -main Main -js main.js. Затем подключите файл через <script src="main.js"></script>.

Как обратиться к DOM браузера?

Через модуль js.Browser: js.Browser.document.getElementById("id"), document.createElement(...) и т.д. Подробнее — на вкладке «DOM».

Чем Haxe отличается от TypeScript?

Haxe компилируется не только в JS, но и в C++, Java, Python, PHP и др. TypeScript ориентирован в первую очередь на JS-экосистему.

Нужен ли Node.js для работы с Haxe?

Не обязательно. Node.js может понадобиться, если вы собираете серверную часть на Haxe/JS или хотите запускать JS-цель вне браузера.

Где искать библиотеки?

В репозитории lib.haxe.org (haxelib). Установка: haxelib install имя_библиотеки.

Что такое build.hxml?

Файл конфигурации сборки: пути к исходникам, главный класс, цель компиляции и флаги. Запуск: haxe build.hxml.

Можно ли писать под Android и iOS?

Да. Через C++ (-cpp) или Java (-java для Android). Для iOS — C++-цель с последующей сборкой в Xcode.

Что такое HashLink?

Современная виртуальная машина Haxe. Быстрее Neko, используется в играх (Heaps.io, HaxeFlixel) и на сервере. Флаг компиляции: -hl.

Есть ли система сборки вроде npm?

Есть haxelib для библиотек и build.hxml для сборки. Также существуют сторонние инструменты (lix, haxelib.json для публикации).

Как отлаживать код?

В JS-цели — через DevTools браузера (source maps включаются флагом -debug). В C++/HL — через отладчик (GDB, Visual Studio) с флагом -debug.

Haxe мёртв?

Нет. Язык активно развивается, выходят новые версии компилятора, есть крупные проекты (Heaps.io, HaxeFlixel, Armory3D). Сообщество небольшое, но живое.

Сложно ли выучить Haxe?

Если вы знаете Java, C#, ActionScript или TypeScript — синтаксис покажется знакомым. Основная сложность — освоить кроссплатформенность, макросы и build.hxml.

Чем Haxe лучше JavaScript?

Строгая типизация, компиляция во много целей, макросы, единая стандартная библиотека. Но у JS больше экосистема и готовых библиотек.

Какие IDE поддерживают Haxe?

VS Code (расширение Haxe), IntelliJ IDEA (плагин Haxe), Vim/Neovim, Sublime Text. Для автодополнения нужен language server.

Как опубликовать библиотеку?

Создайте haxelib.json, соберите архив через haxelib submit, отправьте на lib.haxe.org. Подробнее — на вкладке «Haxelib».

Что такое externs?

Типизированное описание внешнего API (JS-библиотеки). Не компилируется в код, только проверяет типы. Подробнее — на вкладке «Externs».

Можно ли использовать Haxe с React?

Да, через haxe-react или react externs. Также есть coconut.ui — собственный UI-фреймворк.

Что такое DCE?

Dead Code Elimination — удаление неиспользуемого кода при компиляции. Уровни: no, std, full. Флаг: -dce full.

Как работает кроссплатформенность?

Один код компилируется в разные цели. Стандартная библиотека абстрагирует различия, но нативные API требуют условной компиляции (#if js, #if cpp).

Есть ли Haxe для мобильных игр?

Да — HaxeFlixel, OpenFL, Heaps.io, Armory3D. Компилируются в C++ (iOS/Android) или JS (веб).

Что такое Neko?

Виртуальная машина Haxe. Быстрый запуск, небольшой размер, серверные скрипты. Флаг: -neko.

Как подключить C-библиотеку?

Через @:native и externs, либо через HashLink native. В C++-цели можно использовать @:headerCode и @:cppFileCode для вставки C++-кода.

Есть ли async/await в Haxe?

В Haxe нет встроенного async/await, но есть tink_core (Future/Promise), haxe-coroutines, tink_await. В JS-цели можно использовать промисы через externs.

Как использовать Haxe с WebAssembly?

Через C++-цель с компиляцией в WASM (Emscripten). Готовых «из коробки» решений мало, но сообщество экспериментирует.

Что такое inline?

Модификатор, который подставляет тело функции в место вызова. Убирает накладные расходы на вызов, но увеличивает размер кода.

Что такое abstract type?

Обёртка над существующим типом с возможностью перегрузки операторов. Не создаёт новый тип в рантайме (нулевые накладные расходы). Подробнее — на вкладке «Типы».

Как сделать кроссплатформенный HTTP-запрос?

Через haxe.Http (стандартная библиотека) — работает на большинстве целей. Для JS-специфики — js.Browser.window.fetch.

Что такое @:native?

Метаданные, указывающие имя класса/метода в целевой платформе. Используется в externs, когда имя в JS отличается от имени в Haxe.

Как использовать Haxe с Electron?

Через hxelectron — externs для Electron API. Компиляция в JS, упаковка в десктопное приложение.

Есть ли Haxe для Data Science?

Слабо развито. Можно компилировать в Python и использовать pip-библиотеки, но экосистема Haxe в этой области небольшая.

Как обновить Haxe?

Скачайте новую версию с сайта и установите поверх. haxelib сохраняет библиотеки между версиями. Проверьте haxe --version.

Что читать дальше?

Официальное руководство haxe.org/manual, Haxe Code Cookbook, исходники компилятора на GitHub, форум community.haxe.org.
