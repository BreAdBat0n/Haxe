Что такое externs

Externs — это описание внешнего API (обычно JS-библиотеки) в виде классов Haxe. Они не компилируются в код, а только сообщают компилятору, какие методы и свойства есть у внешнего объекта.

Пример: описание простой библиотеки

Допустим, в JS есть глобальный объект MyLib с методом greet(name):

// MyLib.hx
extern class MyLib {
  static function greet(name:String):String;
}

Теперь из Haxe можно вызывать:

trace(MyLib.greet("мир"));

Компилятор сгенерирует вызов MyLib.greet("мир") в JS — без лишних обёрток.

Extern для класса с полями

extern class Vector2 {
  var x:Float;
  var y:Float;

  function new(x:Float, y:Float);
  function length():Float;
}

Extern для функции с колбэком

extern class Fetcher {
  static function get(url:String, onDone:String->Void):Void;
}

Extern с необязательными полями

typedef Options = {
  ?method:String,
  ?headers:Dynamic,
  ?body:String
}

Правила

  • extern — класс только описывает API, не содержит реализации.
  • Тела методов не пишутся — только сигнатуры.
  • Поля без инициализации.
  • Extern-классы не попадают в выходной код.
  • Можно описывать глобальные объекты, классы, функции, typedef'ы.

Где брать готовые externs

Многие популярные JS-библиотеки уже описаны и доступны через haxelib:

haxelib install jQueryExtern
haxelib install three.js
haxelib install hxnodejs

Установленные externs подключаются через -lib имя в build.hxml.

Пример с jQuery

import jQuery.JQuery;

class Main {
  static function main() {
    new JQuery(function() {
      new JQuery("#btn").click(function(e) {
        trace("клик по кнопке");
      });
    });
  }
}
