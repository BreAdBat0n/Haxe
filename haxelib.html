Haxelib

Haxelib — официальный менеджер пакетов Haxe. Каталог библиотек: lib.haxe.org.

Установить библиотеку

haxelib install имя_библиотеки

Например:

haxelib install heaps
haxelib install hxnodejs
haxelib install jQueryExtern

Посмотреть установленные

haxelib list

Обновить

haxelib update имя

Обновить все:

haxelib update

Удалить

haxelib remove имя

Подключить в build.hxml

Библиотека не подключается автоматически — нужно указать её в файле сборки:

-cp src
-main Main
-js bin/main.js
-lib heaps

Установить конкретную версию

haxelib install heaps 1.9.0

Локальная разработка библиотеки

Если вы пишете свою библиотеку, её можно подключить из локальной папки:

haxelib dev имя_библиотеки путь/к/папке

Популярные библиотеки

  • heaps — игровой движок / 2D-3D рендеринг
  • hxnodejs — API Node.js для Haxe
  • jQueryExtern — externs для jQuery
  • three.js — externs для Three.js
  • tink_http — HTTP-клиент
  • tink_json — работа с JSON
  • haxe-ws — WebSocket

Где искать

Каталог: lib.haxe.org. Также многие библиотеки есть на GitHub с тегом haxelib.
