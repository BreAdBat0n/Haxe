Haxelib

Haxelib — официальный менеджер пакетов Haxe. Каталог библиотек: lib.haxe.org.

Установить библиотеку

haxelib install имя_библиотеки

Например:

haxelib install heaps
haxelib install hxnodejs
haxelib install jQueryExtern

Посмотреть установленные

haxelib list

Обновить

haxelib update имя

Обновить все:

haxelib update

Удалить

haxelib remove имя

Подключить в build.hxml

Библиотека не подключается автоматически — нужно указать её в файле сборки:

-cp src
-main Main
-js bin/main.js
-lib heaps

Установить конкретную версию

haxelib install heaps 1.9.0

Посмотреть доступные версии:

haxelib info heaps

Локальная разработка библиотеки

Если вы пишете свою библиотеку, её можно подключить из локальной папки:

haxelib dev имя_библиотеки путь/к/папке

Отключить:

haxelib dev имя_библиотеки

Публикация библиотеки

  1. Создайте haxelib.json с описанием (имя, версия, автор, зависимости).
  2. Соберите архив haxelib submit.
  3. Отправьте на lib.haxe.org через веб-форму.

Пример haxelib.json:

{
  "name": "mylib",
  "url": "https://github.com/user/mylib",
  "license": "MIT",
  "tags": ["utility", "web"],
  "description": "Моя библиотека",
  "version": "1.0.0",
  "classPath": "src",
  "releasenote": "первый релиз",
  "contributors": ["user"],
  "dependencies": {}
}

Зависимости

В haxelib.json можно указать зависимости — haxelib установит их автоматически:

"dependencies": {
  "tink_core": "1.0.0",
  "hxnodejs": "12.0.0"
}

Популярные библиотеки

  • heaps — игровой движок / 2D-3D рендеринг
  • hxnodejs — API Node.js для Haxe
  • hxelectron — Electron для десктопных приложений
  • jQueryExtern — externs для jQuery
  • three.js — externs для Three.js
  • tink_http — HTTP-клиент
  • tink_json — работа с JSON
  • tink_core — базовая библиотека tink
  • haxe-ws — WebSocket
  • openfl — кроссплатформенный фреймворк (Flash-подобный API)
  • haxeFlixel — 2D-игровой движок
  • haxeui — кроссплатформенный UI
  • haxe-strings — утилиты для строк

Где искать

Каталог: lib.haxe.org. Также многие библиотеки есть на GitHub с тегом haxelib.

Кэш библиотек

Библиотеки хранятся в глобальной папке (обычно ~/.haxelib или %HOMEPATH%/.haxelib). Можно указать другую папку через haxelib setup.

Офлайн-установка

Если нет интернета, можно установить библиотеку из zip-архива:

haxelib install mylib.zip

Проверка целостности

haxelib path имя

Покажет путь к установленной библиотеке.

Полезные команды

haxelib install имя      # установить
haxelib list             # список
haxelib update           # обновить все
haxelib remove имя       # удалить
haxelib info имя         # информация
haxelib path имя         # путь
haxelib dev имя путь     # локальная разработка
haxelib submit           # собрать архив для публикации
haxelib setup            # сменить папку библиотек
