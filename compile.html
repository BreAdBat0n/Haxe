Компиляция

Компилятор вызывается командой haxe с флагами цели. Один и тот же код можно собрать под разные платформы.

В JavaScript

haxe -main Main -js main.js

Затем подключите файл на странице:

<script src="main.js"></script>

Быстрая проверка (интерпретация)

haxe -main Main --interp

Код выполняется интерпретатором Haxe без создания файла — удобно для проверки синтаксиса и логики.

В C++

haxe -main Main -cpp bin/cpp

Компилятор сгенерирует C++-код, который затем собирается нативным компилятором (MSVC, GCC, Clang).

В Java

haxe -main Main -java bin/java

Требует haxelib install hxjava.

В Python

haxe -main Main -python bin/main.py

В HashLink

haxe -main Main -hl bin/main.hl
hl bin/main.hl

Файл сборки build.hxml

Удобно хранить флаги в отдельном файле и запускать просто haxe build.hxml:

-cp src
-main Main
-js bin/main.js

Несколько целей в одном build.hxml

-cp src
-main Main

--next
-js bin/main.js

--next
-cpp bin/cpp

Каждый блок после --next — отдельная сборка.

Полезные флаги

  • -cp — добавить путь к исходникам
  • -main — указать главный класс
  • -js, -cpp, -java, -python, -hl, -neko, -php, -lua, -cs — цель компиляции
  • -debug — включить отладочную информацию (source maps для JS)
  • -D — определить флаг компиляции (-D js-es=6, -D analyzer-optimize)
  • --no-opt — отключить оптимизацию
  • -lib — подключить библиотеку haxelib
  • -resource — встроить файл как ресурс
  • -xml — выгрузить XML-описание проекта (для IDE)
  • --each — применить флаги ко всем целям
  • -v — подробный вывод
  • --times — показать время компиляции по модулям

Определения компиляции

Через -D можно включать условные блоки:

#if debug
  trace("отладка");
#end

Сборка:

haxe -main Main -js main.js -debug

Source maps для JS

Флаг -debug автоматически включает source maps. В браузере можно отлаживать Haxe-код напрямую.

haxe -main Main -js main.js -debug

Ресурсы

Встроить файл в приложение:

-resource assets/data.json@data

Доступ из кода:

var data = haxe.Resource.getString("data");

Оптимизация

  • -D analyzer-optimize — включить оптимизатор (рекомендуется)
  • -D no-traces — убрать все trace из сборки
  • --no-opt — отключить оптимизацию (для отладки)
  • -D dce=full — dead code elimination (удаление неиспользуемого кода)

DCE (Dead Code Elimination)

Уровни: no, std, full. Пример:

-dce full

Очистка

Просто удалите выходную папку (bin/) — компилятор не хранит кэш в проекте.

Вывод ошибок

Компилятор выводит ошибки с указанием файла, строки и столбца. Флаг -v добавляет подробности.

Компиляция только изменённых файлов

Haxe компилирует весь проект каждый раз (нет инкрементальной сборки «из коробки»), но использует кэш сервера компиляции (--connect) для ускорения:

haxe --connect 6000 build.hxml

Сервер компиляции запускается отдельно и кэширует результаты между сборками.

Профилирование

haxe -main Main -js main.js --times

Покажет время компиляции по модулям — полезно для поиска узких мест.

Пример полного build.hxml

-cp src
-main Main
-lib heaps
-D analyzer-optimize
-dce full
-debug

--next
-js bin/main.js

--next
-hl bin/main.hl

Типичные ошибки

  • Class not found — проверьте -cp и имя класса
  • Type not found — не подключена библиотека или externs
  • Uncaught exception — ошибка в рантайме, смотрите консоль
  • Source map не работает — проверьте флаг -debug и путь к .map
