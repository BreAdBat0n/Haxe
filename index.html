Что такое Haxe (кратко)

Haxe состоит из высокоуровневого языка и компилятора. Одна кодовая база может компилироваться в разные цели, что позволяет использовать общий код для игр, веба, мобильных и десктопных приложений [citation:10].

Поддерживаемые цели

  • JavaScript — браузер, десктоп, мобильные, сервер
  • C++ — десктоп, мобильные, сервер, консоли
  • Java / JVM / C# — десктоп, мобильные, сервер
  • Python, PHP, Lua — сервер, скрипты, десктоп
  • Neko, HashLink — собственные VM Haxe [citation:1][citation:10]
