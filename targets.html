Поддерживаемые цели

Одна кодовая база Haxe может компилироваться в разные цели. Флаг цели указывается в команде haxe или в build.hxml.

JavaScript

Флаг: -js файл.js

Браузер, десктоп (Electron), мобильные (Cordova/Capacitor), сервер (Node.js). Самая популярная цель.

haxe -main Main -js bin/main.js

C++

Флаг: -cpp папка

Нативная сборка для Windows, macOS, Linux, Android, iOS, консолей. Требует установленный C++-компилятор (MSVC, GCC, Clang).

haxe -main Main -cpp bin/cpp

Java / JVM

Флаг: -java папка

Десктоп, Android, сервер (JVM). Требует haxelib install hxjava.

haxe -main Main -java bin/java

C#

Флаг: -cs папка

.NET / Mono, десктоп, сервер, Unity (через отдельные библиотеки).

haxe -main Main -cs bin/cs

Python

Флаг: -python файл.py

Серверные скрипты, автоматизация, десктоп.

haxe -main Main -python bin/main.py

PHP

Флаг: -php папка

Веб-бэкенд, серверные скрипты.

haxe -main Main -php bin/php

Lua

Флаг: -lua файл.lua

Игры (Love2D, Defold), встраиваемые скрипты.

haxe -main Main -lua bin/main.lua

Neko

Флаг: -neko файл.n

Собственная VM Haxe. Быстрый запуск, небольшой размер, серверные скрипты.

haxe -main Main -neko bin/main.n

HashLink

Флаг: -hl файл.hl

Современная VM Haxe. Используется в играх (Heaps.io, HaxeFlixel) и на сервере. Быстрее Neko.

haxe -main Main -hl bin/main.hl
