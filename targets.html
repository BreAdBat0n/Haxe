Поддерживаемые цели

Одна кодовая база Haxe может компилироваться в разные цели. Флаг цели указывается в команде haxe или в build.hxml.

JavaScript

Флаг: -js файл.js

Браузер, десктоп (Electron), мобильные (Cordova/Capacitor), сервер (Node.js). Самая популярная цель.

haxe -main Main -js bin/main.js
  • Работает везде, где есть JS
  • Полный доступ к DOM через js.Browser
  • Source maps при -debug
  • Можно использовать hxnodejs для Node.js API

C++

Флаг: -cpp папка

Нативная сборка для Windows, macOS, Linux, Android, iOS, консолей. Требует установленный C++-компилятор (MSVC, GCC, Clang).

haxe -main Main -cpp bin/cpp
  • Высокая производительность
  • Доступ к нативным API
  • Используется в играх (OpenFL, HaxeFlixel, Heaps.io)
  • Дольше компиляция из-за нативной сборки

Java / JVM

Флаг: -java папка

Десктоп, Android, сервер (JVM). Требует haxelib install hxjava.

haxe -main Main -java bin/java
  • Интеграция с Java-библиотеками
  • Android-разработка
  • JVM-сервер

C#

Флаг: -cs папка

.NET / Mono, десктоп, сервер, Unity (через отдельные библиотеки).

haxe -main Main -cs bin/cs

Python

Флаг: -python файл.py

Серверные скрипты, автоматизация, десктоп.

haxe -main Main -python bin/main.py
  • Простая интеграция с Python-библиотеками
  • Нет строгой типизации в рантайме (типы проверяются компилятором Haxe)

PHP

Флаг: -php папка

Веб-бэкенд, серверные скрипты.

haxe -main Main -php bin/php

Lua

Флаг: -lua файл.lua

Игры (Love2D, Defold), встраиваемые скрипты.

haxe -main Main -lua bin/main.lua

Neko

Флаг: -neko файл.n

Собственная VM Haxe. Быстрый запуск, небольшой размер, серверные скрипты.

haxe -main Main -neko bin/main.n
neko bin/main.n

HashLink

Флаг: -hl файл.hl

Современная VM Haxe. Используется в играх (Heaps.io, HaxeFlixel) и на сервере. Быстрее Neko.

haxe -main Main -hl bin/main.hl
hl bin/main.hl
  • JIT-компиляция
  • Быстрее Neko
  • Поддержка C-библиотек через native
  • Активно развивается

Сводная таблица

  • JS — веб, Node.js, Electron, мобильные
  • C++ — нативные приложения, игры, консоли
  • Java — Android, JVM-сервер
  • C# — .NET, Unity
  • Python — скрипты, сервер
  • PHP — веб-бэкенд
  • Lua — Love2D, Defold
  • Neko / HashLink — собственные VM Haxe

Как выбрать цель

  • Веб-приложение — JavaScript
  • Игра под десктоп/мобильные — C++ или HashLink
  • Android-приложение — Java или C++
  • Серверный API — Node.js (JS), JVM, Python, PHP
  • Быстрый прототип — JS или --interp
  • Максимальная производительность — C++

Кроссплатформенные ограничения

Не весь код компилируется во все цели. Например, js.Browser доступен только в JS. Используйте условную компиляцию:

#if js
  import js.Browser;
  Browser.document.title = "Haxe";
#end

Стандартная библиотека Haxe абстрагирует большинство различий, но нативные API требуют отдельных externs.

Цели и экосистема

  • JS — самая большая экосистема библиотек (hxnodejs, jQueryExtern, three.js)
  • C++ — OpenFL, HaxeFlixel, Heaps.io, Armory3D
  • HashLink — Heaps.io, серверные фреймворки
  • Java — hxjava, Android-библиотеки
  • Python — интеграция с pip-пакетами
