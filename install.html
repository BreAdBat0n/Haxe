Установка Haxe

Установка состоит из трёх частей: компилятор, менеджер библиотек haxelib и редактор кода. Компилятор и haxelib ставятся вместе.

1. Компилятор

Скачайте установщик с официального сайта haxe.org и установите. После установки проверьте версию:

haxe --version

Вывод должен быть вроде 4.3.4. Если команда не найдена — проверьте, что путь к Haxe добавлен в PATH.

2. Менеджер библиотек haxelib

Устанавливается вместе с компилятором. Проверка:

haxelib version

Основные команды:

haxelib install имя   # установить
haxelib list          # список установленных
haxelib update        # обновить все
haxelib remove имя    # удалить
haxelib dev имя путь  # подключить локальную папку

3. IDE и редакторы

  • VS Code — расширение «Haxe» (подсветка, автодополнение, переход к определению, диагностика).
  • IntelliJ IDEA — плагин Haxe (поддержка проектов, отладка).
  • Vim / Neovim — плагины для подсветки и LSP.
  • Sublime Text — пакет Haxe.
  • Любой редактор с подсветкой синтаксиса — минимально достаточно.

Для полноценной работы с автодополнением нужен language server. В VS Code он ставится вместе с расширением.

4. Структура проекта

project/
├── src/
│   └── Main.hx
├── bin/
│   └── js/
│       └── index.html
└── build.hxml

src/ — исходники, bin/ — результат компиляции, build.hxml — конфигурация сборки.

5. Первый проект: Main.hx

class Main {
  static function main() {
    trace("Haxe is great!");
  }
}

6. build.hxml

-cp src
-main Main
-js bin/js/main.js

Строки означают: добавить src в пути поиска, главный класс Main, скомпилировать в bin/js/main.js.

7. index.html

<!DOCTYPE html>
<html>
<head><meta charset="utf-8"></head>
<body>
  <script src="main.js"></script>
</body>
</html>

8. Компиляция и запуск

haxe build.hxml

Откройте bin/js/index.html в браузере. В консоли (F12) появится Haxe is great!.

9. Установка поддержки Java (опционально)

haxelib install hxjava

Для сборки под Java используется флаг -java в build.hxml.

10. Установка C++ (опционально)

Нужен C++-компилятор: MSVC (Windows), GCC/Clang (Linux/macOS). Затем:

haxe -main Main -cpp bin/cpp

Компилятор Haxe сгенерирует C++-код, который затем собирается нативным компилятором.

11. Установка HashLink (опционально)

HashLink — VM Haxe. Скачайте с hashlink.haxe.org, установите, затем:

haxe -main Main -hl bin/main.hl
hl bin/main.hl

12. Решение проблем

  • haxe: command not found — путь к Haxe не в PATH. Добавьте вручную или переустановите.
  • haxelib не видит библиотеку — проверьте haxelib list, возможно, нужно -lib имя в build.hxml.
  • Ошибка «Class not found» — проверьте -cp и имя главного класса (-main).
  • Кириллица в консоли — используйте UTF-8 в терминале.
  • Старая версия Haxe — обновите с сайта или через пакетный менеджер.

13. Обновление Haxe

Скачайте новую версию с сайта и установите поверх. haxelib сохраняет библиотеки между версиями. Проверьте:

haxe --version

14. Полезные команды

haxe --help          # справка
haxe --version       # версия
haxe build.hxml      # сборка по конфигу
haxe -main Main --interp  # быстрый запуск без файла
