Установка Haxe

1. Компилятор

Скачайте установщик с официального сайта haxe.org и установите. После установки проверьте версию:

haxe --version

2. Менеджер библиотек haxelib

Устанавливается вместе с компилятором. Проверка:

haxelib version

Основные команды: haxelib install имя (установить), haxelib list (список), haxelib upgrade (обновить), haxelib remove имя (удалить) [citation:8].

3. IDE и редакторы

  • VS Code — расширение «Haxe» (подсветка, автодополнение, переход к определению).
  • IntelliJ IDEA — плагин Haxe.
  • Любой редактор с подсветкой синтаксиса — минимально достаточно.

4. Проверка: первый проект

Создайте папку проекта:

project/
├── src/
│   └── Main.hx
├── bin/
│   └── js/
│       └── index.html
└── build.hxml

Содержимое src/Main.hx:

class Main {
  static function main() {
    trace("Haxe is great!");
  }
}

Содержимое build.hxml (компиляция в JavaScript):

-cp src
-main Main
-js bin/js/main.js

Содержимое bin/js/index.html:

<!DOCTYPE html>
<html>
<head><meta charset="utf-8"></head>
<body>
  <script src="main.js"></script>
</body>
</html>

5. Компиляция и запуск

haxe build.hxml

Откройте bin/js/index.html в браузере. В консоли разработчика (F12) должно появиться Haxe is great! [citation:11].

6. Установка поддержки Java (опционально)

haxelib install hxjava

Для сборки под Java используется флаг -java в build.hxml [citation:3].
