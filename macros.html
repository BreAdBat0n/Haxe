Макросы

Макросы в Haxe — это функции, которые выполняются во время компиляции и могут генерировать код, проверять структуру программы или вычислять что-то заранее.

Простейший макрос

import haxe.macro.Expr;

class MyMacros {
  public static macro function hello():Expr {
    return macro trace("Привет из макроса!");
  }
}

class Main {
  static function main() {
    MyMacros.hello();
  }
}

При компиляции вызов MyMacros.hello() заменится на trace("Привет из макроса!").

Возврат выражения через macro-синтаксис

public static macro function twice(e:Expr):Expr {
  return macro ($e + $e);
}

Использование:

var x = MyMacros.twice(5); // превратится в (5 + 5)

Генерация полей класса

import haxe.macro.Context;
import haxe.macro.Expr;

class Build {
  public static macro function build():Array<Field> {
    return [{
      name: "generated",
      access: [APublic],
      kind: FVar(macro:String, macro "сгенерировано"),
      pos: Context.currentPos()
    }];
  }
}

Проверка на этапе компиляции

public static macro function assertPositive(e:Expr):Expr {
  var value = haxe.macro.Context.eval(e);
  if (value <= 0) {
    haxe.macro.Context.error("значение должно быть > 0", e.pos);
  }
  return e;
}

Вычисление констант

public static macro function constAdd(a:Int, b:Int):Expr {
  return macro $v{a + b};
}

$v{...} вставляет значение как литерал.

Чтение файла на этапе компиляции

import sys.io.File;
import haxe.macro.Context;

public static macro function includeFile(path:String):Expr {
  var content = File.getContent(path);
  return macro $v{content};
}

Генерация класса

import haxe.macro.Context;
import haxe.macro.Expr;

class Build {
  public static macro function build():Array<Field> {
    var fields = [];
    for (i in 0...5) {
      fields.push({
        name: "field" + i,
        access: [APublic],
        kind: FVar(macro:Int, macro $v{i}),
        pos: Context.currentPos()
      });
    }
    return fields;
  }
}

Макрос-билдер

Макрос с именем build вызывается автоматически при компиляции класса:

@:build(MyMacros.build())
class MyClass {
  // поля добавятся автоматически
}

Макрос-инициализатор

@:autoBuild(MyMacros.build())

Применяется ко всем наследникам класса.

Условная компиляция (не макросы, но рядом)

#if js
  trace("это JavaScript");
#elseif cpp
  trace("это C++");
#end

Context API

  • Context.currentPos() — текущая позиция в коде
  • Context.error(msg, pos) — ошибка компиляции
  • Context.warning(msg, pos) — предупреждение
  • Context.eval(expr) — вычислить выражение
  • Context.getType(name) — получить тип
  • Context.defined(name) — проверить флаг компиляции
  • Context.getLocalClass() — текущий класс
  • Context.getLocalMethod() — текущий метод

Типичные применения

  • Автогенерация геттеров/сеттеров
  • Проверка конфигурации на этапе компиляции
  • Создание DSL (встроенных языков)
  • Оптимизация: вычисление констант заранее
  • Подключение внешних ресурсов (файлов, JSON) в код
  • Генерация кода из схем (protobuf, JSON Schema)
  • Логирование вызовов методов
  • Проверка инвариантов

Важно

Макросы выполняются в контексте компилятора — они не попадают в выходной код как обычные функции. Для их использования нужен import haxe.macro.*. Отладка макросов — через Context.warning и Context.error.

Ограничения

  • Макросы не могут иметь побочных эффектов в рантайме
  • Нельзя использовать обычные функции времени выполнения
  • Отладка сложнее, чем у обычного кода
  • Некоторые API недоступны в макросах (зависят от цели)

Пример: логирование вызовов

public static macro function log(expr:Expr):Expr {
  return macro {
    trace("вызов: " + $v{expr.toString()});
    $expr;
  };
}

Пример: DSL

public static macro function html(expr:Expr):Expr {
  // разбор выражения и генерация DOM-кода
  return macro trace("сгенерировано");
}
