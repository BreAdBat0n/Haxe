Типы в Haxe

Haxe — строго типизированный язык. Система типов обнаруживает ошибки на этапе компиляции, которые в целевых языках проявились бы только во время выполнения. Типы можно указывать явно или позволять компилятору выводить их.

Базовые типы

  • Int — целые числа (32-битные на большинстве целей)
  • Float — числа с плавающей точкой (64-битные)
  • String — строки UTF-8
  • Bool — true / false
  • Void — отсутствие значения (для функций)
  • Null<T> — nullable-тип
  • Dynamic — динамический тип (отключает проверки)
  • Any — любой тип (включая Void)

Вывод типов

var x = 10;        // Int
var y = 3.14;      // Float
var name = "Haxe"; // String
var list = [1, 2, 3]; // Array<Int>

Компилятор выводит типы из контекста. Если нужно — указывайте явно:

var x:Int = 10;

Классы

class Person {
  public var name:String;
  private var age:Int;

  public function new(name:String, age:Int) {
    this.name = name;
    this.age = age;
  }

  public function greet():String {
    return "Привет, " + name;
  }
}

Использование:

var p = new Person("Иван", 25);
trace(p.greet());

Модификаторы доступа

  • public — доступно отовсюду
  • private — только внутри класса (по умолчанию)
  • static — принадлежит классу
  • inline — подстановка в место вызова
  • override — переопределение метода родителя
  • final — запрет переопределения
  • dynamic — метод можно переопределить в рантайме (для JS)

Наследование

class Student extends Person {
  public var university:String;

  public function new(name:String, age:Int, university:String) {
    super(name, age);
    this.university = university;
  }

  override public function greet():String {
    return super.greet() + ", студент " + university;
  }
}

Интерфейсы

interface IShape {
  function area():Float;
}

class Circle implements IShape {
  var r:Float;
  public function new(r:Float) { this.r = r; }
  public function area():Float { return 3.14 * r * r; }
}

class Square implements IShape {
  var side:Float;
  public function new(side:Float) { this.side = side; }
  public function area():Float { return side * side; }
}

Класс может реализовать несколько интерфейсов:

class MyClass implements IShape implements IComparable { ... }

Абстрактные классы

@:abstract
class Shape {
  public function area():Float {
    throw "не реализовано";
  }
}

Перечисления (enum)

enum Color {
  Red;
  Green;
  Blue;
  Custom(r:Int, g:Int, b:Int);
}

var c = Color.Red;
switch (c) {
  case Red: trace("красный");
  case Custom(r, g, b): trace("rgb: " + r + "," + g + "," + b);
  default: trace("другой");
}

Enum с параметрами:

enum Result {
  Ok(value:Int);
  Error(msg:String);
}

function handle(r:Result) {
  switch (r) {
    case Ok(v): trace("ok: " + v);
    case Error(m): trace("error: " + m);
  }
}

Typedef

Псевдоним типа или описание структуры:

typedef User = {
  name:String,
  age:Int,
  ?email:String
};

var u:User = { name: "Иван", age: 25 };

Псевдоним для простого типа:

typedef UserId = Int;
typedef Callback = String->Void;

Абстрактные типы

Абстрактные типы позволяют создавать «обёртки» над существующими типами с перегрузкой операторов:

abstract Meters(Float) from Float to Float {
  public inline function new(v:Float) this = v;
  @:op(A + B) public static function add(a:Meters, b:Meters):Meters {
    return new Meters(a + b);
  }
}

var m1:Meters = 10;
var m2:Meters = 20;
var m3 = m1 + m2;

Типизированные функции

var fn:Int->Int = function(x) return x * 2;
var callback:String->Void = function(s) trace(s);

Nullable

var maybe:Null<Int> = null;
maybe = 5;

На JVM/CS Null<T> может иметь другую семантику — учитывайте при кроссплатформенной разработке.

Dynamic

Dynamic отключает проверку типов — используйте только при необходимости (например, при работе с внешними JS-объектами):

var obj:Dynamic = {};
obj.anyField = "значение";
trace(obj.anyField);

Any

Any — любой тип, но, в отличие от Dynamic, требует явного приведения для использования:

var a:Any = 5;
var b:Int = cast a;

Массивы и коллекции

  • Array<T> — динамический массив
  • List<T> — двусвязный список
  • Map<K, V> — ассоциативный массив (интерфейс)
  • StringMap<V> — map со строковыми ключами
  • IntMap<V> — map с целочисленными ключами
  • Vector<T> — типизированный массив для C++/Java/CS

Параметризованные типы (generics)

class Box<T> {
  public var value:T;
  public function new(value:T) { this.value = value; }
}

var b = new Box<Int>(5);
trace(b.value);

Ограничения generics

class Container<T:IShape> {
  public var item:T;
  public function new(item:T) { this.item = item; }
  public function area():Float return item.area();
}

Структурные типы

Haxe проверяет совместимость по структуре (duck typing на уровне компиляции):

typedef Named = { name:String };

function hello(n:Named) trace(n.name);

hello({ name: "Иван" }); // ok
hello({ name: "Иван", age: 25 }); // тоже ok

Типобезопасность и приведение

var d:Dynamic = "строка";
var s:String = cast d; // явное приведение

if (Std.isOfType(d, String)) {
  trace("это строка");
}

Void и Never

  • Void — функция ничего не возвращает
  • Never — функция не возвращает управление (бросает исключение или бесконечный цикл)

Сравнение типов

  • == — структурное сравнение для примитивов, ссылочное для объектов
  • Std.isOfType(v, T) — проверка типа в рантайме
  • Type.typeof(v) — получить тип значения
